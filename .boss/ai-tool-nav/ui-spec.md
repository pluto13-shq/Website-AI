# UI 设计规范 - AI 工具导航网站

## 设计风格

- **主题**：深色极简（Dark Minimal）
- **气质**：专业、克制、科技感
- **参考**：类似 Product Hunt / SaaS 导航站

## 色彩系统

| 用途 | 色值 |
|------|------|
| 背景主色 | `#0a0a0f` |
| 背景卡片 | `#14141f` |
| 边框 | `#2a2a3a` |
| 主文字 | `#e8e8ed` |
| 次要文字 | `#8888a0` |
| 强调色 | `#6366f1` → `#8b5cf6` 渐变 |
| 悬停高亮 | `rgba(99, 102, 241, 0.15)` |

## 组件规范

### 工具卡片
- 圆角 12px，内边距 20px
- 左侧 emoji/图标 + 右侧名称与描述
- 悬停：边框变强调色 + 轻微上浮

### 分类标题
- 左侧渐变色竖条装饰
- 字号 1.25rem，字重 600

### 搜索框
- 全宽，圆角 pill 形
- 聚焦时边框高亮

### 广告位
- 虚线边框 + 「广告位」标签
- 居中展示，背景略浅于页面

## 响应式断点

- 桌面：≥1024px — 双栏（导航 + 内容）
- 平板：768-1023px — 导航横向滚动
- 手机：<768px — 单栏，侧边广告移至底部
