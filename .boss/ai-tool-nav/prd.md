# PRD - AI 工具导航网站

## 项目概述

构建一个简洁、深色调的 AI 工具导航 Web 网站，帮助用户快速发现和访问各类 AI 工具。

## 目标用户

- 需要探索 AI 工具的普通用户
- 希望集中展示 AI 工具链接的内容运营者

## 核心功能

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 工具分类展示 | P0 | 按类别分组展示 AI 工具卡片 |
| 搜索过滤 | P0 | 实时搜索工具名称与描述 |
| 分类导航 | P0 | 侧边/顶部快速跳转到各分类 |
| 广告位 | P0 | 顶部横幅、侧边栏、分类间插播位 |
| 响应式布局 | P1 | 适配桌面与移动端 |
| 外链跳转 | P0 | 点击卡片在新标签页打开工具官网 |

## 非功能需求

- 纯静态站点，无需后端
- `npm install && npm run dev` 即可本地运行
- 首屏加载 < 2s（本地开发环境）
- 数据与 UI 分离，便于后续维护

## 内容结构

- 6 大分类：对话助手、图像生成、代码开发、写作创作、视频音频、效率工具
- 每类 4-6 个示例工具（含名称、描述、图标、外链）

## 验收标准

- [x] 深色简洁视觉风格
- [x] 分类清晰可导航
- [x] 至少 3 处广告位可配置
- [x] 搜索可用
- [x] 本地可一键启动
