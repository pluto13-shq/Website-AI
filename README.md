# Website-AI
## 项目概述  构建一个简洁、深色调的 AI 工具导航 Web 网站，帮助用户快速发现和访问各类 AI 工具。  ## 目标用户  - 需要探索 AI 工具的普通用户 - 希望集中展示 AI 工具链接的内容运营者  ## 
核心功能  | 功能 | 优先级 | 说明 | 
|------|--------|------|
| 工具分类展示 | P0 | 按类别分组展示 AI 工具卡片 | 
| 搜索过滤 | P0 | 实时搜索工具名称与描述 | 
| 分类导航 | P0 | 侧边/顶部快速跳转到各分类 | 
| 广告位 | P0 | 顶部横幅、侧边栏、分类间插播位 |
| 响应式布局 | P1 | 适配桌面与移动端 | 
| 外链跳转 | P0 | 点击卡片在新标签页打开工具官网 |
